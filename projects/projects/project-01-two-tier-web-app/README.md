# Project 01 – 2-Tier AWS Web Application

## Overview
This project deploys a highly available 2-tier web application on AWS using best practices for networking, security, and scalability.

## Architecture
- VPC with 2 Availability Zones
- Public subnets for ALB
- Private subnets for EC2 and RDS
- Application Load Balancer
- Auto Scaling Group
- RDS (Multi-AZ)

## Services Used
- VPC
- EC2
- ALB
- RDS
- IAM
- Security Groups

## Status
🚧 In Progress – Planning & Architecture

## Goals
- Deploy infrastructure using AWS best practices
- Add Infrastructure as Code (Terraform later)
- Document architecture and decisions
